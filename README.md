# NFSMW-NX Switch 2 installer

Browser-based installer for the experimental USA Switch 2 port. You need your own Xbox 360 game and the
separately downloaded Switch 2 release NRO. See [website/README.md](website/README.md) for setup and deployment.

Based on [StevensND/nfsmw-nx-installer](https://github.com/StevensND/nfsmw-nx-installer), licensed under GPL-3.0.
